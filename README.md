# 衡势

GitHub 仓库：`FHLZ94/HengshiMacos`。当前版本：0.5.0 开发预览。出品：范光旭。Windows 桌面应用，核心功能使用免费公开数据，尚未完成公开上架验收。

## 当前可用

- 单页纵向信息流：顶部市场研判、全球事件、情绪与量价、短期交易参考、组合估值。浅色 WebView2 界面，圆角与细线强调重点。
- Google News、Fed、SEC 的新闻和公告 RSS；并发抓取、跨源标题去重、本地中文翻译缓存、来源与发布时间。覆盖 NVDA、AMD、TSM、ASML、AMAT、KLAC、LRCX 等 SMH 相关半导体龙头，也支持按公司或主题即时检索；行业关联不等于实时 ETF 成分股确认。
- 同一标题的独立发布媒体数可在事件详情查看；多次转载不等于独立证实。全球事件区可按“我的持仓、SMH 行业相关、光通信、云与算力、存储”筛选，也可输入公司、证券代码或主题后点击“即时检索”获取新的公开 RSS 结果。
- Nasdaq 报价和历史行情、FRED VIX，以及 TradingView 当前价和下一财年 EPS 交叉核对。默认观察顺序为 QQQ、SPY、QQQM、SMH、ORCL、MRVL、MU、LITE、INTC、AVGO、^VIX。基金前瞻市盈率目前没有稳定、可复核的免费来源，界面会明确标为缺失。
- 市场情绪七档、CNN 恐慌贪婪指数、标普 500 成分股 20 日参与度、量价承接代理。用 QQQ/SPY/SMH/VIX 历史相似阶段计算未来五日上涨/下跌及短期底部形成的发生率、95% 区间和按时间回测误差。
- 条件式动作参考：关注价格区间、买入确认价、风险失效价。ORCL、SMH、QQQM、MRVL、LITE、AVGO 已标记为持有；持仓数量和成本仍需用户录入。行情来源价差超过 2.5% 时暂停动作判断。
- 个股未来四季一致预期 EPS、未来十二个月市盈率、Nasdaq 分析师一年目标价、中性倍数下的合理价。真正的一年平均前瞻市盈率从本机逐日快照积累，不用当前 EPS 回填历史。用户可设置中性倍数；历史满足至少 120 个日快照和 270 天跨度后自动提供均值。
- VPN 本地代理探测、来源健康、断网缓存、可选 Ollama 本地事件深度分析。

## 使用

运行 `installer\衡势-安装包.exe`，选择目录；桌面快捷方式默认勾选。安装器为标准 Windows 安装向导，卸载入口显示在 Windows“应用和功能”。本地持仓、设置和新闻数据库保留在 `%APPDATA%\AIMarketIntelligence\`，卸载程序默认不会删除它们。

首次打开读取本地缓存并后台同步。肥猫云开启且本地端口 `127.0.0.1:7890` 可用时，Google News、历史行情和翻译会自动使用该代理。也可在数据来源板块填写显式 HTTPS 代理。行情来源可能限流或短暂失败，界面显示最近可得数据时间与连接状态。

本地数据库、设置和日志位于 `%APPDATA%\AIMarketIntelligence\`。可选 Ollama 本地模型分析单条新闻；未安装时基础功能可用。

## 开发构建

安装 Python 3.11，在 Windows 运行 `build_windows.bat`。脚本创建独立虚拟环境并输出中文名称的安装包。代码检查：`python -m unittest discover -s tests -v`。

## 数据边界

免费数据不保证交易所实时级别。新闻等级与情绪先经标题初筛；重点事件会尝试读取原文，抽取事实并核对事件后的行情，来源受限时标明证据边界。转载不等于独立证实。标普 500 参与度基于成分名单快照，不代表官方实时全市场广度；量价不能识别真实机构买盘。历史相似阶段发生率不是已校准的预测概率，界面同时显示样本数、区间及其是否优于回测基线；当前五日方向模型在按时间回测中尚未优于简单基线。价格区间和交易动作是有条件的研究参考，不能替代个人风险预算。分析师目标价与中性估值合理价是两种口径；一年平均前瞻市盈率在快照不足时显示积累中。缺失数据不补零。公开发布前还需数据使用条款、代码签名与干净机器验收。具体发布条件见 `RELEASE_PRODUCT_SPEC.md`。
