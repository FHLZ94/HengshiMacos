# 衡势 1.2 正式版

出品：范光旭。版本：1.2.0。仓库：FHLZ94/HengshiMacos。

衡势使用免费公开信息与本地缓存，围绕市场状态、全球事件、板块资金偏好、条件式交易参考及未来估值组织证据。Windows 使用 WebView2，Intel 与 Apple Silicon Mac 使用对应架构的隔离 Electron 窗口与同一套 Python 分析服务。

## 当前功能

- 市场研判：CNN 恐慌贪婪、标普500广度、量价承接、QQQ、SMH各自的三日/五日上涨与十日低点守稳参考。约十年历史、多因子训练、过去数据校准与时间顺序检验；缺乏额外预测优势时显示历史基准。分别显示计算时间和行情日期，离线可用已有历史重算。
- 全球金融情报：官方公告与多家媒体RSS，去重、中文翻译缓存、来源发布时间、原文事实、方向与影响等级，以及事件后的价格核对。新闻因果与市场反应分别说明。
- 板块轮动：科技、半导体、消费、医药、公用事业等，以及黄金与长期美债。周/月正负柱图展示量价资金偏好代理，并结合相对标普强弱给出观察结论。
- 可维护跟踪：默认 VGT、SPY、QQQM、SMH、ORCL、MRVL、MU、LITE、INTC、AVGO、GOOG、SKHY。卡片右上角可移出跟踪，右侧可按代码新增美股或ETF；识别身份后自动同步行情、目标价、盈利预期、历史和资讯。删除跟踪保留实际持仓。QQQ等模型基准保持独立，不占用跟踪卡片。
- 报价：纳斯达克与CNBC免费接口，区分常规交易和盘前盘后；以交易日期与时段核对，较旧时段不覆盖更新成交。名称后显示最近可得价格，触发条件另列。
- 统一估值：仅展示当前滚动PE；明确未来12个月管理层EPS指引与同口径历史PE中位数可用时优先计算，否则采用分析师目标价中位数。交易卡片、估值表、事件详情共用同一参考价，以同一当前价计算空间。亏损标的标注PE不适用，不用正的前瞻PE替代。
- 基金估值：QQQ/SPY的同源PE月度历史分位、QQQM的同指数代理，以及VGT发行人季度报告PE。历史不足时保留空缺。
- 实际持仓、设置、翻译和事件库均存于本机，升级保留数据。

## 1.2 新增

- 顶部改为加仓条件、QQQ/SMH双指数概率、双向超买超卖历史位置、15/30/60分钟背离、事件风险与承接结论；标普广度保留在分析依据中。
- 白宫公开总统行动、国会/AI监管和半导体公开言论优先流每两分钟核对；支持补充原始X公开帖子链接。未接入需登录的X全站时间线。
- 事件阶段、可靠性、证据与时效用于动作风险层；消息分数不直接加减概率。不可变研究快照为后续前瞻验证保留当时证据。
- 完整计算规则与权重说明见 `docs/model-1.2.0.md`。

## 安装与使用

Windows 运行 `installer/衡势-安装包.exe`，按标准安装向导选择位置与桌面快捷方式。Intel Mac 安装文件为 `衡势-1.2.0-macOS-Intel.dmg`；M系列 Mac 安装文件为 `衡势-1.2.0-macOS-Apple-Silicon.dmg`。

Windows 用户数据目录为 `%APPDATA%/AIMarketIntelligence/`；macOS 为应用数据目录中的衡势文件夹。连接设置在右上角设置按钮。可自动探测本地代理 `127.0.0.1:7890`，也可填写显式代理。基础功能无需付费金融API或本地大模型；可选 Ollama 用于进一步分析。

## 构建与检验

Python 3.11。Windows 执行 `build_windows.bat`，测试执行 `python -m unittest discover -s tests -v`。Mac 可运行仓库的手动 GitHub Actions 工作流，按架构生成 Intel 和 Apple Silicon DMG；云构建保留DMG artifact，不自动创建公开Release。跨平台设置见 `README-Mac.md`。

## 数据口径

免费行情可能延迟。板块承接得分是量价代理，不代表真实机构净买入额；一年估值空间属于盈利兑现与倍数保持的情景。历史发生率、校准概率及分析师目标价分别标注，不将重叠样本当作独立年度胜率。不同会计口径的EPS与PE不直接混用，不用当前EPS回填历史估值。具体模型与既有验证见 `docs/research-0.6.0.md`，开发过程见 `衡势-Vibe-Coding-开发案例.md`。

版本标识为1.2正式版。两个 DMG 由对应架构的 macOS 云构建环境生成；实体Mac验收及Apple开发者签名、公证状态单独记录。
