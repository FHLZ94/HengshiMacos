# 衡势 1.1：统一参考价与短线模型说明

## 先看什么

顶部首先回答未来一至三个交易日的交易环境，再同时展示QQQ、SMH的五日上涨参考、十日低点守稳、超卖历史位置及实时事件风险。标普广度保留为辅助依据，不再单独占顶部卡片。

“明显超卖”表示价格在自己的历史分布中偏低；“小额分批候选”还需要量价修复、三日上涨参考不低于50%、近期事件风险不高、价格未跌破风险线。50%仅是方向性门槛，不是最优仓位或收益保证。若仍缺承接，显示等待条件。重大已核验负面事件或实时价格跌破风险线时，优先提示控制敞口。

## 一家公司只有一条统一参考记录

每次刷新以同一份报价快照计算，每个标的生成一个参考记录，供交易卡片、估值表和事件详情共用。

1. 有明确的未来十二个月管理层EPS指引，并取得同口径历史PE中位数时：参考价＝管理层EPS×历史PE中位数。管理层指引使用100%，不再与分析师EPS按70/30混合。
2. 缺少明确指引、历史样本不足，或者调整盈利与会计盈利口径不一致时：采用来源发布的分析师目标价中位数。
3. 只有平均目标价时不冒充中位数，没有有效中位数时保留空缺。旧版手动情景倍数、当前PE乘分析师预测EPS的自算价格、历史年度收益率，不再成为另一个并列参考价。
4. 参考空间始终＝统一参考价÷当前价－1。关注区间用于入场条件，不改变这个百分比的分母。

分析师中位数目前通过TradingView公开扫描接口取得，接口支持 `price_target_median`。它与纳斯达克One Year Target等综合均值可能不同。没有披露逐个银行目标价的接口，不虚构银行名单及样本数；有逐项报价时，同一机构只保留最新一期，再计算中位数。

历史PE目前使用可核对的历史观测，按季度保留最后观测，计算近五年正盈利季度的中位数；至少需要12个有效季度和三年跨度。亏损期间PE不适用，不用今天的EPS反推历史PE。管理层调整口径EPS与会计口径历史PE不能直接相乘。接口或口径受限时回到分析师中位数。

估值表只列当前滚动PE。计算优先使用当前价÷历史十二个月会计EPS；亏损时标注不适用，不以正的前瞻PE替代。基金没有公司式分析师目标价时，不用过去一年收益率生成目标价。

2026-11-08的验收数据中，GOOG统一参考价390美元，ORCL为232.5美元。相对同一份当前报价，分别约+37.1%与+100.5%；卡片、估值表和事件详情一致。这是当时的数据快照，后续随报价与预测更新。

## QQQ与SMH如何分别计算概率

两者分别训练、校准和检验，使用各自未来价格定义结果：

- 三日上涨：第三个交易日收盘高于最新完整交易日收盘。
- 五日上涨：第五个交易日收盘高于最新完整交易日收盘。
- 十日低点守稳：未来十个交易日最低价不低于本日最低价，且第十日收盘高于本日收盘。这个可检验事件用于评估低点能否守住，不能等同于已识别长期底部。

使用QQQ、SPY、SMH、VIX约十年的共同日线。尚未收盘的交易日不纳入；VIX仅使用当时已知的记录。没有把今天的CNN指数或今天的成分股广度倒填成过去数据。

| 特征组 | 输入 |
| --- | --- |
| 动量 | 本标的5、20、60日收益，按对应波动率标准化 |
| 趋势位置 | 价格相对20、60日均线的偏离 |
| 回撤 | 63日高点回撤，按波动率标准化 |
| 相对强弱 | 本标的相对SPY、SMH相对QQQ的五日强弱 |
| 风险环境 | VIX对数水平、五日变化、20/60日实现波动率比 |
| 量价承接 | 当日成交量相对前20日均量、收盘在日内区间的位置、下跌与放量的交互 |

合计14个特征。输入只用该预测时点之前的数据计算。

## 权重来自哪里

候选模型是带L2正则的逻辑回归。特征先在训练窗口中标准化；系数由历史数据拟合，不人为规定“VIX占多少百分点”或“某条新闻增加20%上涨概率”。界面的展开项会列出各标的候选模型的标准化系数及绝对系数占比。后者帮助比较模型敏感度，受相关特征影响，不代表因果贡献。

每63个交易日重新训练，最多使用最近1260个交易日，至少先积累约504日训练。训练标签必须已在预测时点结束。训练标签可以重叠，时间顺序检验和校准按对应期限使用已到期、不重叠的观测，避免未来结果泄露。

用过去样本外预测做sigmoid校准，再按固定的保守方案收缩：65%校准模型＋35%历史基准。只有至少40次已到期检验、校准样本足够，且候选概率误差较基准改善超过0.001时，才使用该方案；否则使用100%历史基准，并直接标注。这个收缩比例是公开的设计参数，未宣称它是普遍最优比例。

历史基准由不重叠样本的上涨次数计算，并做平滑；Brier误差衡量概率与真实0/1结果的距离，越小越好。区间是历史发生率的Wilson区间，不是证明今天真实概率的置信保证。未能胜过基准时，模型不会为了“看起来有预测能力”而调高数字。

## 超买、超卖与市场阶段

将价格相对20日均线的偏离，用同期实现波动率标准化，然后与此前历史观测比较。下侧分位越小，表示相对少见的低位；上侧分位越小，表示相对少见的高位。

- 历史下侧5%以内且RSI14低于40：明显超卖；下侧1%以内且RSI14低于35：极端超卖。
- 历史上侧5%以内且RSI14高于60：明显超买；上侧1%以内且RSI14高于65：极端超买。
- 超卖但尚无量价修复：超卖观察，等待承接；多周期底结构、放量承接、三日上涨参考不低于50%并且事件风险较低时，才可显示小额分批候选。
- 超买且分钟级顶背离确认：高位背离，复核敞口；超买但没有背离：偏热拥挤，避免追价。
- 高位时，若价格接近20日高位、最近推进小于0.35倍真实波幅，同时量比偏高或压力得分显著为负：高位滞涨，放缓追价。它是价量拥挤代理，不是账户持仓统计。

这些是透明的条件规则，不把相关指标简单相乘成虚假的“见底胜率”。日线概率与超买超卖特征在新交易日到来后更新；盘前盘后报价、新事件和分钟结构可以先改变风险提示与动作条件。

## 新闻怎样动态影响判断

当前事件风险层使用：事件强度×来源可靠性×证据充分度×指数相关度×时效衰减。它是风险排序分，不是涨跌概率。

- 事件阶段分别识别公开表态、提议/呼吁、议案通过待生效、行政措施、正式生效。
- 官方原文、公司原始发布、权威媒体、单一公开帖子分别赋予不同来源与证据等级；否认、传闻和未核验说法降低权重。
- 个人表态及提议的影响分设上限；单条X言论上限30分，不能仅靠发布者知名度被当成正式政策。
- 政策事件按48小时、其他事件按24小时半衰期衰减。依据原始发布时间，不以刷新时间变新。
- 重复报道不累计成多倍冲击，重大负面不被多条普通利好平均抵消。
- 高影响且已核验的负面风险可以否决加仓候选；未核验消息先形成待核对的条件提醒，不直接生成“90%下跌”。

这套事件权重属于透明规则，目前没有足够的历史时点新闻样本支持可信的新闻条件概率。程序因此保留量价历史概率，同时动态更新事件风险与动作，而不把20分影响变成20个百分点概率变化。按当时时点保存、不可覆盖的研究快照，用于后续前瞻检验；未来新闻模型还需要按当时可执行交易时段重新匹配收益标签。

## 公开言论与覆盖范围

优先同步白宫公开总统行动、国会/AI监管、半导体公司与相关公开言论，重点流每两分钟核对，媒体引用与正式文件交叉阅读。支持在设置中补充原始X公开帖子链接，通过公开嵌入接口读取可访问内容，并保留原始发布时间。

免费公开接口不能保证覆盖X全站实时帖子，也不读取需登录或受保护的时间线。没有取得内容时不编造言论。公开帖、媒体转述、正式政策分别标注，市场同日下跌也不直接作为该条消息造成下跌的证明。

## 分钟结构与承接

程序获取QQQ和SMH最近一个月的15分钟完整K线，再严格按美东09:30开始聚合30分钟与60分钟K线。尚未完成的K线不参与背离，60分钟最后不足一小时的尾盘桶单独标记；不同交易日不拼接。

RSI使用Wilder RSI14，MACD使用12/26/9。价格低点或高点必须由左右各两根已经完成的K线确认；右侧K线尚未完成时只显示候选。底背离要求后一个低点更低且RSI或MACD低点抬高；顶背离反向定义。15分钟信号不会推断30或60分钟必然成立，多周期共享成交数据，不能把三个信号相乘成概率。

成交量比同一标的、同一美东盘中时刻的过去样本比较，减少开盘和尾盘天然放量的误判。承接由价格位置、量比和近三根K线的收盘位置计算：多周期都放量承接才称为多周期放量承接；只有部分周期改善时称初步承接；量价方向相反时称承接偏弱或放量卖压。

顶部卡片只呈现阶段结论，例如“底结构修复、量能待确认”“放量承接增强”“高位滞涨”或“顶部背离风险”。展开说明提供15/30/60分钟的RSI、底背离、顶背离、同时间段量比和美东时间。分钟数据缺失、超过五日或市场关闭期间，不保留旧信号冒充实时结论。
